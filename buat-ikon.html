Pembuat ikon aplikasi

Pilih file logo kamu (PNG atau JPG). Semua ikon dibuat di browser ini, tidak ada yang diunggah ke mana pun. Area putih di sekitar logo dipotong otomatis, lalu logo ditaruh rapi di tengah kotak persegi.

Langkah selanjutnya

  1. Taruh kelima file hasil unduhan di folder yang sama dengan index.html. Jangan ubah nama filenya.
  2. Upload semuanya ke hosting kamu (harus https).
  3. Android / Chrome: buka web, lalu menu ⋮ → Instal aplikasi (atau Tambahkan ke layar utama).
  4. iPhone / iPad: buka di Safari, tekan tombol Bagikan → Tambah ke Layar Utama.
